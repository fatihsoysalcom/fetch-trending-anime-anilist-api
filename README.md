# Fetch Trending Anime AniList API

This example demonstrates how to fetch trending anime data using the AniList GraphQL API. It makes a client-side API call to the AniList endpoint and displays the fetched anime titles and cover images on a simple HTML page. This showcases the core concept of interacting with the AniList API to retrieve public data for building a personalized dashboard.

## Language

`html`

## How to Run

Save the code as `index.html`.
Open `index.html` in any modern web browser.
